<p align="center">
  Silly Launcher is a custom launcher for Minecraft that allows you to easily manage multiple installations of Minecraft at once.<br />
  This is a fork of Prism launcher, which is a remake of PolyMC, which is a fork of MultiMC.
</p>

<p>!!! This is not a continuation of Prism, nor meant for regular usage, this is a passion project !!!</p>
